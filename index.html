Paper → Podcast

Drop in a PDF, get back two hosts talking it through for as long as you asked for. References and appendices are stripped, figures are pulled out, and the whole thing can run on your own machine with local models, local speech and local transcription. The hard part isn’t the audio: a model explaining a paper will invent things fluently, so every claim in the script is scored against the source, and the finished audio is transcribed back to check it still matches.

Code reviewMulti-agent

Loupe

Python

Reviews a local diff or a GitHub pull request from your terminal. Four specialists read the change at once, each hunting a different class of defect, and a separate gate re-checks what they filed against the full source with instructions to reject. What survives arrives with a failure scenario, the line it rests on and often a one-click patch, next to a diagram of how the change hangs together. Review the same branch twice and it tells you what you fixed instead of repeating itself.
